# Provenance

I built this repository from VOLLEY commit
[`aa22a06`](https://github.com/aaaaaaaaaaaavm/VOLLEY/commit/aa22a069e5d2b4e4c58428904fedeafbcf594e46),
the commit that reconciles the corrected thrust quadrature, A6 covariance bound, A12 force
plane, A13 internal-momentum result, brake-fin mass and thermal inputs. Every retained file
is byte-identical to its blob in that commit. `SOURCE_MANIFEST.json` records per-file SHA-256
values and an aggregate snapshot hash as a second, independently checkable identity.

The retained files establish what was computed and which committed state it came from. They
do not establish that a motor was built,
that a field or force was measured, or that any external organization endorsed the result.
